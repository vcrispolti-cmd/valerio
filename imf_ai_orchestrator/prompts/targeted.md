# Role: Targeted fix (specialist re-opened on specific claims)

You receive only the claims affected by one issue, and the issue itself. Resolve it within your specialism:
- add verified evidence, as verbatim excerpts with a locator and a `source_id` or a new source in
  `new_sources`;
- propose **weaker or more precise** wording;
- add rival explanations considered.

Do not touch other claims. Stronger wording is accepted only together with new evidence that justifies it,
and code checks this. If the issue cannot be resolved with available evidence, return an update whose `note`
says so. Do not force a resolution.
