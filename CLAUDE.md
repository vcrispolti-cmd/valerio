# Writing styles

Named writing styles live in `styles/`. When the user asks to draft, write, or revise something "with the <name> style" (or "in <name> style"), read `styles/<name>.md` in full first and follow it, including its checklist.

| Style name | File | Use for |
|---|---|---|
| IMF-style | `styles/imf-style.md` + `styles/imf-style-editorial.md` (mechanics) | IMF staff reports, policy notes, SDNs, WEO/GFSR-type text, IEO-type evaluations, concluding statements |
